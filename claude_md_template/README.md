# CLAUDE.md template — Next.js + SQLite SaaS

Drop-in `CLAUDE.md` for a Next.js (App Router) + TypeScript + SQLite (better-sqlite3/Drizzle) + Tailwind SaaS.
Encodes the architecture map, conventions, SQLite-sync gotchas (WAL, no-await, transactions, serverless cold-start),
commands, definition-of-done, and guardrails — so Claude Code is productive on day one.

Usage: copy `CLAUDE.md` to your repo root, adjust the `pnpm` scripts to match your `package.json`.
